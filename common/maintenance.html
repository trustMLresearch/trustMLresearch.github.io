日常只编辑 HTML

保存修改，再像以前一样上传或提交到网站，然后刷新网页。公共框架由浏览器自动加载，不需要 Python、配置文件或生成命令。

修改内容直接编辑的 HTML
电脑和手机主菜单common/menu.html
年份菜单common/years.html
网站名称、公共页头、页面框架和页脚common/layout.html
首页资助信息、免责声明和新闻common/home-footer.html
讲座正文、照片链接、讲者介绍和摘要seminar-talks/对应文件.html
年份表格、团队成员和其他页面正文直接编辑原网址对应的 index.html

公共 HTML 的 head 中已有自动加载脚本，保留这些行即可；日常修改 body 中的菜单、年份或页脚内容。

菜单链接怎么写

公共文件中的链接以网站根目录为基准，不用区分首页、talk 页面或年份页面的文件夹深度。例如在年份列表中加入：

<li><a href="online-seminar-series/2027-Jan-Dec/index.html">Jan-Dec 2027</a></li>

先创建对应的年份页面，再加入该链接。电脑和手机菜单都会使用同一份列表。

新增 Talk

  1. 复制 seminar-talks/ 下一个现有 HTML，使用新的文件名。
  2. 编辑其中 page-content 内的标题、照片、讲者介绍和摘要。
  3. 按原来的方式，在年份页面的表格中添加这场讲座的链接。
  4. 保存并上传或提交文件。无需登记 JSON，也无需生成网页。

页面标题和样式

<template id="page-heading">…</template> 是页面蓝色横条中的标题。浏览器标签标题仍由 HTML 的 <title> 控制。

现有样式保存在 assets/css/；加载哪些样式由 common/layout.html 控制。JavaScript 只负责自动加载和菜单交互，日常无需修改。

预览方式

可以直接双击本地 index.html 预览，也可以通过网站的 HTTP/HTTPS 地址查看。公共 HTML 会自动加载，日常不需要启动服务器或运行命令。请保留网站中的 common、assets、wp-content 和 pic 文件夹。

讲座信息没有集中成数据库，照片文件和图片质量没有修改，两个旧团队链接的跳转也保留。
